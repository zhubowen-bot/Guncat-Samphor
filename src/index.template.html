默认设置

  • 模型：Qwen2.5-0.5B（本地）
  • 质量档位：平衡（固定）
  • 运行后端：自动（WebGPU 优先，WASM 兜底）
  • 压缩：关闭（保证流式显示）
  • 公开开头：每次随机生成，自动附加在隐语文本开头

怎么用？

  • 在“隐藏信息”里输入秘密文本，点击生成；开头会自动随机生成并包含在文本里，整段复制发给对方。
  • 对方在“提取信息”里粘贴完整文本，点击提取。不需要填写开头、选择模型或档位。
  • 模型权重首次使用会缓存到浏览器；之后刷新只重建运行会话，不再重新下载 750 MB。

这一版改进了什么？

  • 修复原版遗留问题：原版 2M 模型按 4096 词表采样、可见字符却只有 609 个，越界 token 会变成空白；该实现仅保留作历史对照与测试，当前界面只使用 Qwen2.5-0.5B。
  • 质量感知采样：固定使用平衡档位（温度 0.90、top-p 0.95），并配合重复惩罚、自然字符过滤、无重复 3-gram 和隐藏提示词，显著降低胡言乱语。
  • 近熵算术编码：用 32 位区间算术编码替代原来的“top-64 二元区间”方案。每个 token 可承载接近其信息熵的比特数，分布失真更小，速度更快。
  • 可靠的帧格式：88 位头部（魔数、版本、模型、档位、nonce、长度、CRC32）+ UTF-8 + 可选 deflate 压缩 + 白化。文本被改动、开头不一致或档位不对时会明确报错。
  • 模型本地集成：Qwen2.5-0.5B q4 ONNX 与 Transformers.js/ONNX Runtime 全部放在本地，运行时不再访问外网。
  • 大模型接入：Qwen2.5-0.5B（ONNX / WebGPU / WASM）通过自定义 logits processor 接入。为消除 BPE 分词歧义，只接受能保持“规范分词”的 token：解码端对正文重新分词即可无损还原。

安全边界

编码端与解码端使用相同的固定模型与平衡档位。平衡档位会调整温度和截断，因此它相对的是“调参后的模型分布”，而不是原始模型分布； 若需要更接近可证明安全的原始分布，可在源码中改用容量档位（温度 1.0、top-p 1.0、不过滤字符）并重新生成。算术编码的有限精度量化会带来极小的分布误差。 隐写不等于加密：请勿在没有额外加密的情况下传输高敏感内容。

模型加载、缓存与运行后端（高级）

Qwen2.5-0.5B 的 q4 ONNX 权重与 Transformers.js/ONNX Runtime 都在浏览器本地运行；权重来源见上。

首次使用会把约 750 MB 权重缓存到浏览器 OPFS；之后刷新页面不再重新下载，模型初始化通常只需几秒。ONNX/WebGPU 会话本身无法跨刷新保留，因此无法做到真正的 0 加载；需要完全 0 加载只能使用常驻的本地进程或常开标签页。

Qwen 优先使用 WebGPU；无 WebGPU 或 WebGPU 加载失败时自动使用 WASM（较慢）。Qwen 分布已按后端无关的粗粒度 logits 量化，并固定候选顺序，以降低 WebGPU/WASM 之间微小数值差异导致的解码失步；仍建议同一条消息尽量在同一后端编解码。

请通过本地 http 服务打开（file:// 无法读取模型文件）。

自检

用 Qwen2.5 本地模型跑一次“编码 → 解码”闭环，确认当前浏览器环境正常（首次会加载本地模型）。
